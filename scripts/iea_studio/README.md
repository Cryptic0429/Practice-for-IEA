# IEA 智能修图工作室（`scripts/iea_studio/`）

本工作室集成了**多轮对话修图 Agent**（主视图）与**核心/基线同场对照**（辅助视图）：

## 1. 对话修图工作台（默认主视图）

- **无损重算与版本回溯**：系统永久保存初始原图，每一轮对话仅更新累计的 9 维全局调色参数，并直接从原图重新渲染；支持一键撤销、还原原图或点击时间轴跳转到任意历史轮次。
- **双模式协同与自检闭环**：
  - 在配置完整视觉语言底座的 GPU 环境下（`--enable-agent-vlm`），对话规划与视觉复检通过禁用适配器调用原生底座完成，参数决策则启用调色主干与控制头；
  - 在无 GPU 的本地环境中自动以**CPU 规则演示模式**运行多轮状态管理、确定性渲染与毫秒级硬指标护栏，界面清晰标注当前引擎模式；
  - 渲染后自动执行高光溢出/暗部死黑检查与视觉复检，风险过高时按比例衰减幅度重试或自动回退。
- **示例图库入口**：顶栏「示例图库」与画布空状态均提供历史样例弹窗入口，不占用主编辑区域。

## 2. 基线效果对照（次级视图）

同一界面保留了**IEA 智能调色核心**、**无控制头消融版**与**早期功能基线**的同图同指令双语对照能力（共 6 项结果），支持盲测隐藏方案名、1:1 原像素查看与人工评价记录。

## 当前运行边界

- **未自动部署**：本地重构不会同步或重启 `SJTU1` 上既有的服务器服务；`bash scripts/iea_studio/open_local.sh` 仅用于端口转发连接既有服务。
- **本地测试**：安装 `configs/mainline/requirements-cpu.txt` 后可运行 `make test-runtime` 验证会话接口、对比接口与编辑器不变量。
