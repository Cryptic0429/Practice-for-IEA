# 方法核对与本轮边界

此文献核对在两路训练启动后补充；未据此改动已经冻结的公式、数据、超参数、更新次数或功能门槛。

[SimPO（NeurIPS 2024原论文，§2.2–2.3）](https://proceedings.neurips.cc/paper_files/paper/2024/file/e099c1c9699814af0be873a175361713-Paper-Conference.pdf)使用平均序列对数概率、无需参考模型的偏好目标，并设置胜负间隔。本轮排序项对应这一形式：比例32、间隔1，额外权重0.1，叠加每条记录的正例助手CE。32、1和0.1是本实验冻结的选择，论文不构成本项目这些超参数有效或修图会变好的证据。论文主要在语言模型对话任务验证，不能将其成绩转述为图片编辑能力。

[POVID原论文摘要](https://arxiv.org/abs/2402.11411)讨论视觉语言模型忽略或误述图像的问题，并使用包括图像扰动在内的办法构造偏好数据。它支持进一步检验图像条件依赖这一研究方向。本轮的具体负例是已有修复参数在轻重输入之间互换后执行出的图片，逐图核验后选择；没有使用未校准评审器自动给奖励，也没有将该论文结论直接应用为本项目验收结果。

本轮输入始终是原图、单个原始语言要求和固定工具说明。正负候选只用于助手监督与打分。正例CE每条都保留，以限制仅降低负例概率而损坏原能力的可能性；是否实际保留能力仍需20/20保持与拒绝控制、原始请求、旧回归和各类图片检查。数学掩码／梯度检查与修图效果分别记录。

额外局限：交叉负例并不必然等于模型最常输出的错误答案。父模型在本轮19个明确偏好上，平均概率排序已正确28/38条语言记录，仍可能把第三个、未列为交叉负例的答案作为greedy输出。只提高正例相对一个负例的概率，不能据此宣布实际解码已正确。若冻结的最终检查点仍出现此现象，应先用训练池实际输出和可见效果定位，再决定是否收集新的明确偏好；不能自动把每个不同参数当成错误。

参考资料仅用于解释方法形式和局限，最终选择仍完全由冻结的逐图功能门槛决定，L1与训练损失不参与。
