# 数值精度核查：没有新的模型或功能改善结论

使用同一个第十一轮父模型和三个原训练池英文输入，对比重新加载适配器的通常推理路径与训练准备后切换eval的路径。没有优化器步骤，没有使用目标标签、开发或验收图，没有执行修图工具。此核查与第十四轮训练、第十五轮阴影工具原型分开记录，未更改第十四轮运行设置。

实际检查发现：通常重新加载时，视觉patch卷积、词嵌入、第一层输入归一化、末尾归一化和输出头均为BF16；训练准备后这些模块均为FP32。量化权重仍为uint8存储。三个输入的最后前缀logit最大差异分别0.46875、0.75、0.576171875，完整贪心输出却全部逐字相同（3/3）。

这说明数值路径确有差异，但不能据此解释此前修图失败，也没有证据表明换成其中一种就更好。三个训练输入不是普遍一致性证明。本轮没有新标签、没有新训练策略模型、不做默认替换，也未用此结果调整当前冻结评测。进一步采用任何路径前仍需单独冻结并做实际图片功能对照。
