# 第九轮：重新比较完整权重起点（已完成训练与逐图开发评审，未通过）

目标是检验新建语言层 LoRA 能否摆脱已有适配器的固定增强习惯。第七轮的决策训练和视觉合并层没有消除重大画质问题；第八轮 EditScore 方向／画质校准失败，不能作为强化学习奖励。本轮不再使用这个评审器选标签或奖励。

实际训练完整复用第七轮已准入的数据：160个原图组，人像和风景各80；462语义案例、924条不同中英文记录，含379编辑、60保持、23拒绝。97例保留原始英文请求，其余365例为标记清楚的AI任务。数据源为 `data/training/functional-v7-20261105/train-accepted.json`，本轮的 `data-reuse.json` 记录身份与来源，没有新添标签。中英文不是独立图像样本。

比较两个完整权重起点：原始 Qwen2.5-VL-7B 与现有作者 IEA；两者各新建一个语言层 q/v LoRA，不继承旧适配器，不叠加适配器。作者权重历史上存在 GIER 原图重叠，不能作为干净的独立泛化或因果对照。全部分片逐字节 SHA 匹配历史身份收据；两路线共享原始 Qwen 的处理器、提示与聊天模板，924条序列的词元编码和8条图像张量探针已CPU核验一致。配置文件字节不同，没有将它们视为同一个模型。

两路线均使用NF4双量化、BF16计算、rank8/alpha16、有效batch4、学习率1e-4、4轮、种子20261115，924个优化步骤，每231步保存检查点。训练前冻结输入白名单、标签重放、模型来源、代码、比较口径与功能门槛；每步检查112个FP32可训练LoRA张量和有限梯度，底座及视觉参数冻结。两个新适配器的随机种子在创建前重设，以核对初始LoRA相同。

编辑器、决策JSON、中文与英文提示沿用冻结第七轮。可行任务的拒绝仍算未完成；明确拒绝不得产生任何结果图。原始请求开发集至少16/20、旧回归至少4/6、无重大副作用，并通过20/20保持／拒绝控制，才进入100例可控开发集。之后仍需同预算复核和锁模才能开封验收。L1、训练损失和评审器分数不用于选模。

截至训练冻结，原16 GPU小时上限已使用11.58759小时，余4.41241小时；本轮使用GPU0/3训练，GPU2逐一运行两套未加新LoRA的对照与后续检查点。GPU1原作者演示服务保留。训练尚不等于完成修图要求；结果须等逐图功能评审，本轮尚未产生可采用的新模型。

[冻结训练协议](training-protocol.json)、[功能验收协议](evaluation-protocol.json)、[权重与输入审计](origin-audit.json)是复核入口。现有可操作试用仍见 [第七轮入口](http://127.0.0.1:12346/v7)，它明确显示未通过实用性门槛，不能将它称为本轮新模型。

未加新LoRA的起点对照已完成。原始Qwen在相同新运行流程下为原始请求开发8/20合格、3例重大副作用，旧回归2/6，保持／拒绝控制0/20。作者IEA在52条真实修图语言记录中均未返回符合新协议的有效输出（51条格式错误、1条截断），保持／拒绝控制也为0/20，因此其0例重大副作用不能解释为安全或可用。这不是作者原演示流程的成绩。新的训练结果必须另与更强的同流程旧默认模型13/20、2例重大副作用、旧回归4/6比较，不能仅依靠消除格式错误宣布进步。
