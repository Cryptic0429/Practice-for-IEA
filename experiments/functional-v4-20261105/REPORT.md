# 第四轮：让模型读取当前图片的亮度和色彩观测

状态：训练和开发逐图复核完成，两条路线均未通过预先固定的升级门槛，高实用性目标尚未达成。开始于2026-11-05（上海时间），目录日期标记本轮开始日；随机种子20261108只是固定种子，不是训练日期。

前两轮已经更会遵从方向和复合要求，但不同问题程度、不同语言仍容易套用不合适的幅度。第三轮37条偏好的小规模优化没有提高6条原始请求的完整合格数。本轮检验一个新的输入假设：为模型提供当前像素的低层描述，能否比同等继续训练更好地选择力度。它不是已证实的改进，也没有用亮度数值代替功能验收。

两路线都从第二轮课程e3开始，使用完全相同的实际标签、顺序、种子、工具和优化次数。普通路线输入照片与原始要求，测量路线额外输入从同一张视觉输入计算的亮度均值、标准差、分位数、RGB均值、饱和度和明暗像素比例。两者有相同的工具说明和质量提醒。测量先按训练／推理共用的视觉尺寸取得RGB，再计算，不读取参考成品、原始规范图、参数标签、任务类别或评审意见。输入隔离检查已验证：篡改这些禁止字段不会改变实际编码；同一要求放在两种退化程度照片上会得到不同的像素观测。

实际训练数据为370语义案例、60原图组（人像／风景各30）：360个已核验可控任务，加10条保留GIER原始英文的自然请求及中文翻译。10条自然请求各重复10次以加强原生照片与自然措辞覆盖。共920条实际记录，其中不同语言记录只有740条；实际记录按域各460条。原始自然请求占语义案例10/370，重复后的相关语言记录200/920，不能把重复采样或翻译当成更多独立原图。360个受控请求为AI构造，自然请求的中文版本为AI翻译。

沿用第三轮快照中6个有明确图像偏好证据的标签修订，保留每次旧值、新值、原图、结果和观察SHA；不修改已冻结的第二轮实验。所有370个目标已重放并逐像素核对；训练输入、实际标签与来源见 `data/training/functional-v4-20261105/cases.json`、`train-accepted.json` 和 `admission.json`。本轮不把未复核的第三轮错误候选纳入训练，也不使用开发／验收原图。

两路线均为NF4 QLoRA、语言q/v、rank8／alpha16、冻结视觉层、有效batch4、学习率5e-5、2轮／460次更新，每轮保存检查点。测量路线的文本更长，因此实际GPU占用可能更多，按占用分别结算，不宣称GPU计算量严格相等。模型只监督参数JSON；非法输出仍明确失败，不把原图回退算作修图成功。

开发预先固定为20张照片的100语义任务（人像／风景各10张）及6张已用于诊断的原始请求开发探针；中英文总共各200和12条，但不作独立样本。另评估未经本轮训练的同一父权重在两种新输入下的表现，区分输入／提示改变与训练贡献。晋级要求两组均无严重副作用、原始请求双语完整合格超过3/6、受控任务不低于81/100。先看原始请求的真实完成，再看受控任务和配对图片，L1、参数距离和训练损失均不参与选择。未达到要求则报告该输入假设下的小实验失败。

20张验收原图仍封存。任何最终推理前都要锁定权重、输入路线、提示和编辑器；开封后不切换检查点或修改参数。最终判断仍为AI辅助直接视觉评审，用户实际试用单独记录。

第四轮独立使用 `scripts/functional_v4/runtime.py`，前三轮的冻结运行时和编辑器保持原样。测量字段以整数0..1000记录，阈值含义由代码和 `input-audit.json` 明确；它们是输入观测，不能解释为验收分数。底座仍为原Qwen加当前一个adapter。

计算继续累计到最初16占用GPU小时总上限，只用0／2／3，GPU1原作者服务保留。训练和离线评测使用0、3，现有试用worker使用GPU2。本轮两条第1轮诊断权重已接入试用，默认模型未更换。试用页可查看四轮实际训练图片、成功、失败和不确定结果。

## 实际开发结果与失败决定

所有6个模型均完成100语义任务×中英文及6条原始请求×中英文的推理。新复核70个受控结果、18个原始请求结果；其余147和16个不同图像仅在同案例、同要求、同输入、同输出像素SHA及旧评审联系表SHA全部相同时复用已有直接视觉观察。联系表隐藏模型身份、参数和参考图；评审仍知道实验背景，不能称为独立人类双盲。细小或边界变化保留不确定，不算合格。

|parent-plain|73|5|3|1|

|plain-e1|79|2|2|0|

父模型的测量输入另有开发2条、原始请求2条饱和度越界；均明确失败，没有截断或修复成成功。四个本轮训练检查点均无非法输出，但都存在严重质量问题。两路线各自比新提示下的父模型好一些，仍没有超过原第二轮课程e3的81/100、原始请求3/6，更没有消除重大损伤；输入提示改变本身也会改变旧模型行为。

主要失败可直接查看 `review/development/all-input-routes/` 和 `review/natural-use/all-input-routes/`：

- 每个训练检查点都保留 `development-055-restore-exposure-strong` 的严重英文过曝；除measured-e2外也保留001的严重过曝。人物白衣、面部变白，不能以调用了曝光工具算合格。
- 原始019“明显提亮并变暖”，训练模型常只输出暖色，漏掉提亮；这是复合要求失败。
- 原始030“大幅调暗”，中文常仍只有轻微调整；measured-e1英文改用阴影调节也没有实现明显整体调暗。
- 较强褪色恢复仍易不足，个别对比任务和微小变化无法可靠判断，保留不确定。

**没有合格冠军，没有升级默认模型，没有换种子复核，验收仍封存。** 为方便比较，注册两路线第1轮作为诊断参考；这不是按合格门槛选出的优胜模型。所有4个检查点和2个未训练父模型的结果均可在试用页查看。本轮只否定“在当前小数据和训练设置下追加这些观测即可解决实用性”的假设，不能据此断言视觉统计或继续监督训练普遍无效。
