# IEA 功能优先实验：24 GPU 小时交付总结

这轮完成了数据审计、功能验收框架、模型训练、直接看图复核和试用接入。**没有得到可确认稳定实用的新模型。** 实际用去23.99923538698091 GPU小时，预算24小时，余量约2.75秒用于退出；原演示GPU1保留，试验默认模型没有更换。

1. **工具和验收。** 对比度的负方向和零点语义已修复；独立实验编辑器支持明确的全局棕褐工具、保持原样及无图拒绝。老编辑器和历史结果仍可对照。先冻结要求、需保留内容和失败现象，再评具体图像。中英文按原图组统计，L1、执行率、训练损失只作诊断。过去看过的case-12与其他历史图只作回归，不充当全新独立验收。
2. **数据。** 旧3000条审计确认510条空指令。首轮实际功能训练220案例／440条中英文；后续扩展到979个图像条件案例、1958条中英文、240原训练原图组（120人像、120风景）。其中802编辑、80保持、76质量拒绝、21工具不支持拒绝。第22轮从既有32组原图构造64个欠曝／加噪候选，实际执行192种图像结果并看图，准入22编辑和32拒绝，剔除10个不确定。新增原图0、仅一个新双语要求模板；拒绝覆盖55原图组。合成噪声不能替代真实相机照片。
3. **训练与结果。** 先后试过不同LoRA起点、偏好纠错、编辑器和标签修正、图像条件特征、小头和直接LoRA。第21轮首种子受控82/100，但换种子后夜景噪声回归，未采用。第22轮两组CPU头各固定1160步，旧回归4/6、6/6，原始开发15/20、13/20。第23轮两组直接LoRA各固定250步，每组只实际呈现1000条，旧回归3/6、4/6，原始开发均16/20。最新两轮保持／拒绝控制均20/20，确认重大0但争议留不确定。第23轮仅第二组达到第一阶段门槛，两组路线未同时通过；未开封最终验收。详见[第22轮](../functional-v22-20261107/REPORT.md)、[第23轮](REPORT.md)及[完整实验历史](../../实验记录与结论.md)。
4. **图上能看到的改善和缺陷。** [历史case-12](report-panels/case12-http.jpg)的两份新LoRA实际给出了棕褐结果；比历史参考更低饱和，仍只是历史回归。人像复合增强仍有偏色和暗发层次损失。[真实夜景](report-panels/night-original-native-pixels.png)中文提亮后彩噪更显，英文却拒绝；第22轮两头在同一图双语都拒绝。58组完整导出对照中没有因缩放/JPEG翻转编辑／拒绝，但复现这组中英文不一致。参数差异和该小组稳定性不代表普遍画质。所有功能判断是AI辅助，独立用户试用反馈0。
5. **试用和可复核交付。** [查看第23轮逐例图和判断](http://127.0.0.1:12346/v23?kind=evaluation)、[第22轮实际训练标签](http://127.0.0.1:12346/v22)、[试用入口](http://127.0.0.1:12346/)。本轮第22轮12次HTTP及2次浏览器成功、另一次真实加载失败保留；第23轮8次真实接口检查。已操作上传、模型切换、编辑、拒绝无图、下载和隔离反馈。结算后新实验推理暂停，已保存图片可看可下载，[原作者 IEA](http://127.0.0.1:12345/)继续独立可用。未改线上默认模型，也未将上传/反馈纳入训练。
6. **下一步优先级。** 若将来继续，先补真实高ISO、夜景、人像肤色和高反差天空的正反案例：在同一原图上对比合理幅度、过量副作用与明确拒绝，分别看主体、天空、噪声和层次。先用相同照片验证中文与英文是否选择一致，再评独立原图。现有证据支持优先解决真实数据覆盖与执行后的画质判断，尚不足以支持继续扩大同类LoRA训练。
