# 四候选交互对比台（2026-11-10）

比较对象为 R1、R15、R23、R15 + R21。可上传同一张图片，填写中文和英文指令，查看八项结果；支持前后滑杆、隐藏模型身份、原尺寸检查、PNG/ZIP 下载及偏好记录。

[候选检查点、启动命令和预算机制](../scripts/comparison_studio/README.md) · [源码](../scripts/comparison_studio/) · [机器可读验证摘要](COMPARISON_STUDIO_VERIFICATION.json)。

## 本机访问与连接恢复

在已有实验服务器 SSH 权限的本机，从项目根目录运行：

```bash
bash scripts/comparison_studio/open_local.sh
```

然后打开 <http://127.0.0.1:12348/>。服务部署在现有实验服务器，仅监听回环地址；此地址不是 GitHub 托管的公网网站。2026-11-10 曾出现本机 SSH 转发断开，重建转发后首页、健康检查、配置及任务列表均恢复 HTTP 200，服务与已有结果无需重启或重建。

运行依赖实验环境中的底座模型、三个 LoRA、R21 控制头、样例图片及 Python 环境。GitHub 只保存源码和文本证据；缺少上述文件时，仅克隆仓库无法直接推理。

## 比较与预算边界

输入统一为相同 EXIF 方向和 RGB 像素，GPU 路径共用 NF4/BF16 底座、262144 像素模型输入上限及确定性生成。实际编辑和下载保留统一原图尺寸。R1 使用首轮提示和编辑器，其余使用 R15 协议及编辑器，因此比较的是完整修图方案，不能把差异全部归因于权重。R15 + R21 复用 R15 的决策和冻结表示；展示的控制头追加耗时不代表完整推理耗时。

此前 24 GPU 小时训练预算已结算，模型未达到稳定实用标准。本次验证与交互试用单独设置 2 GPU 小时上限；验证快照累计 0.05886 GPU 小时，之后的实际用量以运行账本和页面为准。重启不重置预算。个人上传、任务记录和偏好反馈存放在被 Git 忽略的运行目录，不随本次 GitHub 更新发布。
