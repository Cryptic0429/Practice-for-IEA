# Technical Reports

This directory contains LaTeX sources, TikZ vector diagrams, and verification metadata for two project reports:

- `mainline-technical-20261113/`: Concise technical report covering the core architecture (`r15 + r21_head`), baseline ablations, and multi-turn Agent design. Build with `make report` (requires Tectonic + CJK/Arial fonts).
- `model-review-20261112/`: Historical full-model review sources and pre-generated evidence tables covering earlier iterations.
