# 第二十二轮实际采用数据

已逐图核验后采用979个图像条件案例／1958条中英文记录，仍为240原训练原图组，人像／风景各120。旧925案例原样继承此前AI准入记录；本轮从32个现有TRAIN组制作64候选，实际执行192次编辑并逐一看图，另对64个所选结果／失败证据按训练条件原尺寸复核，最终增加22编辑、32质量拒绝，排除10项不确定。新原照片、新独立原图组均0。

总计802编辑、80保持、76质量拒绝、21工具不支持拒绝。质量拒绝覆盖由23增至55个原图组。原始英文案例154，AI构造825；新增54案例使用同一个AI双语请求模板，不能说新增54种独立文字语义或108张照片。合成欠曝及Gaussian噪声不等同真实相机噪声；训练条件最大边1024，原始照片和变换参数均可溯源。
