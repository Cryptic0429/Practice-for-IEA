# 第二十轮实际训练数据

直接逐字节继承第十九轮已核验的925个语义案例，1850条中英文输入，240原图组；人像120组，风景120组。翻译、条件版本和每轮重复都不是新的原始照片。

实际动作：{'edit': 780, 'unreliable_quality': 44, 'keep': 80, 'unsupported_tools': 21}。原始英文154案例、AI构造771，原英文对应中文为AI翻译；本轮无新照片、请求或参数正标签。保持与拒绝有明确动作标签；拒绝不含修图结果。继承视觉核验只覆盖原已采用标签，本轮没有把自动参数拟合或CPU契约测试当成新视觉核验。来源和SHA在[source-manifest](source-manifest.json)，原准入证据在[第十九轮](../functional-v19-20261107/admission.json)。

实际训练读取[cases.json](cases.json)的原图路径、原中英请求和decision标签：原图和请求只进冻结编码器，decision仅进CPU预测头监督；参考图、标签、任务类型、caseID及评审不进入编码。train-accepted.json是同份数据的旧SFT序列格式并留存核对，本轮不从它读取额外数据。

每轮925案例各呈现ZH/EN一次，每16语义组成32语言输入的配对batch，58步/轮，共80轮4640步。实际训练为148000语言呈现/路线，两个路线相同预算，不能和之前的2轮QLoRA说成相同训练步数。训练归一化和方向类别权重仅由TRAIN估计。开发/验收按原图组隔离，中英文同组。

五类全局调整及复合要求与保持/拒绝都保留。工具同R15共9个（含此前为棕色调加入的sepia），不新增局部移除、去噪或分辨率恢复能力。严重质量不能可靠完成应拒绝且无结果；训练动作学得是否正确需要后续实际验收，不能由数据条数推断。

实际两路线CPU训练均完成、4检查点核验完整，但均未过功能门槛。最终结果见[实验报告](../../../experiments/functional-v20-20261107/REPORT.md)；标签不代表模型已学会，用户反馈未进入训练。
