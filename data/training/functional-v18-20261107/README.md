# 第十八轮训练数据：原有正例加可见的强弱交叉负例

状态：两路各2轮1002步已完成，四个检查点均未通过功能门槛。数据为训练前冻结，实际训练与结果见实验目录REPORT.md、development-selection.json和runs/*/status.json。

925个语义案例、1850条中英文输入、240个原图组，人像和风景各120；780编辑、80保持、65拒绝。154例保留原始英文，771例为已标记AI构造或改写；本轮新增原图、请求改写和正例参数标签均0。`cases.json`、`train-accepted.json`与第十五轮逐字节相同。原图与近重复隔离沿用相同R13/R15来源证据，本轮重新查哈希与分组，不冒充新全池扫描。

新增的是19个既有语义案例的明确图像偏好，双语共38条，来自10个既有原图组（人像6、风景4；语义案例人像12、风景7）。较弱或较强退化条件之间互换已有参数，实际执行后逐图核验，正例是原有合格结果，负例是当前图片下明显过调或仍未修复的交叉结果。它们不是19张新照片或新真实相机任务。

12个候选配对的概览全部实际查看，11对补看整张原尺寸输入及正、负结果，共66张。5个语义案例没有强制建立偏好：一条海景曝光的较亮版本同样合理，另一组日落的颜色力度存在分歧，两条近单色雪景也看不清优劣。原始概览与原尺寸分歧完整保留。概览隐藏候选身份，但评审者已见过数值诊断，并在原尺寸复核时知道映射；属于AI辅助评审，不是完全盲审或用户认证。

每轮实际呈现1850条既有正例，加38条偏好各重复4次，共2002条。重复、翻译不算独立照片或新增样本。两条路线使用相同正例、顺序、重复、父适配器、种子和1002次更新；普通监督对照仅学习正例，排序路线额外学习同一输入下已核验的负例，额外前向和GPU消耗单独记录。全部输入始终只含原图、单个原始语言要求和工具说明。正负结果、标签、评语、案例编号和条件名称不进入推理输入。

`preferences.json`保存38条选择、实际图片路径和哈希、逐条原尺寸意见；`training-pool.json`保存2002条每轮呈现记录；`admission.json`记录实际规模与来源。负例CPU缓存223MB在服务器实验目录，沿用的1850条完整CPU缓存由第十五轮完整归档提供。16条偏好候选的答案token长度不同，因此新排序目标分别归一化助手答案概率，不能直接按整段总概率偏好短数字。

没有试用上传或反馈自动进入训练。独立用户反馈仍为0。最终验收保持关闭，训练损失和L1均不作功能改善证明。
