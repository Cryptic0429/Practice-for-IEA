# 第 26 轮 · 同图偏好候选

`inputs/` 保存 16 张 GIER 存档原图的字节一致副本。请求由 AI 编写并按组保存中英文。候选参数全部使用 R15 编辑器执行，原图和输出都绑定 SHA-256。

- [逐图记录](reviewed-candidates.json)保存 56 个编辑的参数、结果路径、结论和视觉依据，包含部分完成及不确定结果。
- [严格偏好候选](preference-candidates.json)保存 10 个同图同要求下的完成与失败对，共 8 个原图组。人像 3 组、风景 5 组。
- [核验凭证](receipt.json)记录来源、AI 评审和训练准入状态。仅用于本轮 CPU 排序诊断，正式训练池的新增准入量为零。
- [逐图报告及结果](../../../experiments/functional-v26-20261107/REPORT.md)包含完整输出的对照、排序结果和局限。
