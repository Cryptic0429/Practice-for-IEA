# 第十三轮实际训练数据

本轮实际采用925个语义案例，中英文1850条，240组原图（人像／风景各120）。翻译版本始终按同一语义、同一原图组统计。详细清单为cases.json；实际行表为train-accepted.json，每个语义各中文、英文一次，无重采样。

继承第十一轮672个案例及完整标签证据，新增253个案例、80组原训练池照片（人像／风景各40）。新增232编辑、20明确保持、1工具不支持拒绝；包括73对两端均经实际图片核验的同图相反要求。整份训练共780编辑、80保持、65拒绝。154个语义保留原始GIER英文并由AI译中文；771个为明确标注的AI请求。新增原始英文57个。AI改写不冒充原始请求，失败的原始请求也不因改成更容易的新请求而算完成。

新增照片仅指未进入当前R9→R11父路线，来自已有GIER原训练池，不是新采集用户照片；旧3k模型可能接触过原池，Qwen预训练接触史未知。未使用试用上传、反馈、开发／验收图。原图及近重复检查见实验目录source-isolation-extended.json，自动检查无标记，人工保守排除相关山景等来源；这不保证检测到所有同地点拍摄。

所有新增标签均实际执行第十一轮冻结编辑器，直接查看候选图片；存在人脸、衣服、天空、雪地、暗部或夜景细节风险时补充原尺寸或整数坐标裁剪核验。253个新增案例仅采用完成C且画质A；37条失败候选／修订记录单独保留在excluded-attempts.json（含同一请求不同尝试，不能当37个独立来源）。原先672个保留既有AI证据与不确定性，不计为本轮新独立评审。

原方案的冻结Qwen初筛此前在评审校准中失败，本轮明确采用Codex直接AI视觉核验准入，未将不可靠模型意见当作第二张有效票。这是对最初初筛流程的明确调整；不代表人工／用户认可。有限参数尝试失败不证明照片对所有参数都不可编辑，不会自动补成拒绝标签。

模型只接收输入照片、一条原始中文或英文要求、冻结工具说明，只监督决策JSON。参考图、目标图、标签、评审、照片统计、任务类别不进入模型输入。1850条均通过元数据污染白名单检查，925个目标均通过编辑器精确像素回放；保持结果逐像素等同输入，拒绝没有结果图。
