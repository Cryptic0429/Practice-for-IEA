# 第二十一轮实际训练数据

原样继承第二十轮已核验的925个语义案例／1850条中英文输入／240原图组，人像风景各120组。翻译、合成条件和每轮重复不计独立照片。新增照片、请求、正参数标签0；没有试用上传或反馈。

780案例为可采用编辑、80保持、44质量拒绝、21工具不支持拒绝。质量拒绝覆盖23原图组，其中同图不同要求仍按一个原图组统计；该部分不能代表全部真实画质失败场景。154案例为原始英文及AI中文翻译，771为AI构造。来源和文件SHA见[source-manifest.json](source-manifest.json)；原视觉准入证据沿[此前记录](../functional-v19-20261107/admission.json)，本轮没有伪称重新逐图核验925标签。

[cases.json](cases.json)为实际监督来源。编辑标签只监督正幅度，正负方向、工具启用与保持／拒绝语义由冻结R15模型决定。质量头仅在780编辑与44质量拒绝上监督；80保持、21工具不支持不参与质量分类。冻结7B只读取图片、字面要求和工具说明，标签、参考图、类别及评审不进入编码。

两种子20261205、20261206各自训练CPU预测头80轮／4640步，各148000条语言呈现，共296000，每种子保存e20与e80。同一种子的两种推理策略共用同一权重，只比较是否采用质量拒绝；种子2是独立训练的锁定复核。训练归一化与风险类别权重只用TRAIN，开发/验收始终与训练原图组隔离。原train-accepted.json与training-pool.json留存核对，不额外抽取新标签。

局部亮度／色度残差来自原图512像素缩略图，只作为学习输入；残差包含真实细节，不能直接作为画质好坏或必须拒绝的规则。没有去噪／分辨率恢复／局部编辑工具。评测按完成修图要求与基本质量判定，不能用参数误差或L1替代。[当前结果](../../../experiments/functional-v21-20261107/REPORT.md)。

首种子质量策略开发暂合格，但锁定e20换种子后确认夜景重大噪点，本路线复核失败；没有增补该开发图到训练，没有开封最终验收，没有升级默认。实际用户认可0。
