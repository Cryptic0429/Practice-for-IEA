# 第十五轮实际训练数据

本数据集已通过 CPU 重放与输入审计，已实际用于第十五轮2轮926步GPU训练。它是旧训练池数据的工具修正版本，不是新增照片集或独立验收集。

| 项目 | 实际数量 |
|---|---:|

| 中英文记录 | 1850（同语义同原图组） |

`cases.json` 保存原图路径及哈希、未改写中英文要求、明确验收条件、实际参数、执行后的目标图和完整来源／评审记录。253例缺失的结构化条件已从原请求及统一画质要求补写，明确标记为 AI 派生评审元数据，不是原始标签。

`train-accepted.json` 是1850条实际监督记录。只监督严格参数／动作JSON。推理输入只包含原图、该语言的原请求和固定工具说明；参考图、正确参数、任务类别、验收条件、评审意见和历史证据不进入模型输入。要求保持时返回原图；拒绝不产生图片。工具范围为现有R11九工具契约（含sepia），本轮只改变阴影运算，其他行为完全继承。

132个原候选均经直接AI看图，并完成116个必要原尺寸补查：121例完成且画质可接受、7例画质不合格、4例部分完成。11例不合格／部分完成均有明确选择的合格修订。未选修订中仍有未完成原尺寸判定的候选，它们没有进入训练。`failed-proposals.json` 与实验目录保留原失败及所有修订记录。

65例拒绝中，44例为既有画质可靠性标签、21例为工具不支持。44例用新工具再次实际尝试、看图，其中3例补查原尺寸；本次尝试均未通过画质要求。保留拒绝仅表示既有有限候选与新尝试中未找到可靠结果，不声称所有参数组合都不可能成功。40个严重噪声案例明确来自人工合成的受损条件，不能当成40张真实新增照片。

本轮沿用R13完全相同的原图／条件／分组，继承既有全池指纹检查并重新检查与冻结开发／验收原图组不重叠；没有把翻译当独立样本。近重复检测仍有漏检相关拍摄的可能。试用上传和反馈完全不进入训练。

全部判断为AI辅助评审，不是人工或用户认可。原始Qwen评审器在R8校准失败，本轮未将其用作入库判断依据，属于对最初批量初筛计划的明确调整。793个完全重放案例继承旧证据与限制，不伪称新看了793例。
