# 第 33 轮对比度训练与留出

- `fit-candidate-records.json` 包含来自 R32 的两组原图与视觉判断。16 个 GIER 原训练池原图组，32 个双向语义任务，128 个真实渲染候选。每个候选包含原图、输出、两者 SHA-256、对齐的中英文要求、配方、判断、全图及空间特征和自动面部框。
- `held-candidate-records.json` 包含全新的 12 个原图组，24 个语义任务，96 个候选。留出样本未进入本轮拟合或校准。`held-inputs/` 保留原图的字节副本。
- 两种语言共用图像候选。本轮训练选择器的输入是图像特征，语言路由未训练。96 个留出候选原尺寸文件保存在服务器。图板、权重、评估、画质及来源验证见 [实验报告](../../../experiments/functional-v33-20261107/REPORT.md)。
