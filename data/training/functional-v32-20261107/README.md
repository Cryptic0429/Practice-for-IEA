# 第 32 轮对比度选择器数据

- `fit-candidate-records.json` 是实际拟合数据。8 个已查看的 GIER 原训练池照片，每张分别发出增强和柔化两个请求，每个请求执行四个候选，共 64 行。
- `held-candidate-records.json` 是独立诊断数据。8 张本轮留出的原训练池照片，人像和风景各 4 张，共 16 个语义任务、64 个候选。记录原图与完整候选的相对路径及 SHA-256、编辑方向、对齐的中英文请求、直接看图的判断和用于模型的数值特征。
- 中英文描述同一语义，使用同一次渲染。此处训练的是选择已渲染结果的 CPU 分类器，语言文本未输入分类器。
- `held-inputs/` 保存 8 张留出原图的字节副本。完整 128 张候选留在服务器实验目录。对应匿名图板在本地实验目录。
- 照片来源、像素级去重范围和逐图结果见 [第 32 轮实验报告](../../../experiments/functional-v32-20261107/REPORT.md)。
