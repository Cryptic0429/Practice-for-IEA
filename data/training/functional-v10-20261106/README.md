# 第十轮实际训练数据

240 个语义案例、480 条不同中英文记录，来自原训练池中的 60 个原图组（人像、风景各30）。父检查点此前在160组上训练；本阶段没有新增原图组，也没有使用试用上传或反馈。训练文件为 `train-accepted.json`，具体输入、要求、决策及目标图片见 `cases.json`，逐条标签依据见 `label-lineage.json`。

200个新增AI案例使用20张照片（各10张），每张10个任务：显著提亮、增加对比度＋稍提亮＋鲜明色彩分别用于深欠曝、正常原图、轻颗粒、强彩色块／条带四种输入；另在正常原图与增亮输入上各要求大幅压暗。相同正常输入有相反方向的风格要求，同一句请求跨照片条件既有编辑又有画质拒绝。曝光与噪声均为明确记录的人工合成条件；不是20张新照片，更不是真实相机噪声样本。

另40个锚点原样继承第七轮的输入、要求、决策、实际结果和AI核验依据，使用其余40个训练原图组：30个编辑（五类各6、人像／风景各3）、5个保持、5个不支持操作拒绝。编辑锚点中27个保留GIER原始英文，3个白平衡风景请求由AI构造；控制请求也由AI构造。因此全体27个原始英文案例（配AI中文翻译），213个AI案例。不得把原始英文比例写成30/240，或把所有请求称为真实用户请求。

最终189编辑、5保持、46拒绝：41画质拒绝、5不支持工具拒绝。41画质拒绝包括20组强退化输入上的两种要求，以及1张正常白衣合照的大幅提亮要求。已执行并查看多种补偿方案，仍未得到完成要求且画质可接受的结果；这只是当前工具和已尝试方案的判断，不证明所有可能方法均无解。轻颗粒、正常及深欠曝可编辑反例用于避免一概拒绝。

全部20组候选的阶段面板与原尺寸风险图均由Codex直接查看；肤色、云层、暗部细节不合格的旧候选保留并排除，修订目标另行执行、原尺寸查看后才采用。40锚点明确继承旧核验，不宣称本轮40次独立复核。自动L1和奖励分数不参与标签选择。原始Qwen与EditScore此前校准失败，因此不作为可靠第二评审。所有判断均为AI辅助评审，无用户认可。

准入前检查通过：原图与合成条件重放、240条决策／目标逐像素重放、480条输入白名单与标签污染测试，以及训练／开发／验收的原图组隔离。近重复排除沿用此前原160组的原始来源审计。只读取留出组元数据与哈希用于隔离，未开启验收推理。
